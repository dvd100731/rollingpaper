# 작업 명세 — 김윤수 생일 롤링페이퍼

## 요청
단일 `index.html`(HTML/CSS/JS)로 동작하는 모바일 최적화 실시간 공유 생일 롤링페이퍼.
- 주인공: 김윤수 / 생일: 11월 5일
- 컨셉: 파스텔 포스트잇 + 귀여운 강아지, 메인 컬러 노랑·분홍

## 완료 기준
1. 헤더 "김윤수의 생일을 축하해!" + 꽃가루 애니메이션 + 메시지 개수 카운트
2. 카드 Grid, 카드별 기울기·파스텔 배경, 하단 `From. 이름` 강조
3. 카드 클릭 → 상세 모달(긴 글 읽기)
4. 우하단 `축하 남기기 +` → 이름·내용·5색 선택·4자리 삭제 비밀번호 입력 모달
5. 비밀번호 일치 시에만 삭제
6. firebaseConfig 입력 시 Firestore 실시간 공유(onSnapshot)
7. 설정 전에는 LocalStorage + 더미 3개로 에러 없이 작동
8. 끝에 Firebase 설정법·Netlify Drop 배포법 안내

## 변경 허용
- `index.html`, `.ai-work/*` 생성

## 검사 허용
- 스크립트 문법 검사(node), 로컬 브라우저 렌더 확인(가능 시)
- 외부 배포·Firebase 프로젝트 생성은 하지 않음(사용자 몫)
